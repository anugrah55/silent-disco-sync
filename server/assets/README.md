# Track library

Drop up to three royalty-free / CC0 audio files here (mp3, m4a or wav, max 12 MB each)
and list them in `tracks.json`. Audio files are git-ignored, so the repo stays small;
the server lists missing files as unavailable instead of crashing.

## Where to find CC0 / royalty-free music

- **Free Music Archive** — https://freemusicarchive.org (filter by license: CC0)
- **Pixabay Music** — https://pixabay.com/music/ (Pixabay Content License, no attribution needed)
- **ccMixter** — https://ccmixter.org (check each track; prefer CC0 / CC BY)
- **OpenGameArt (music)** — https://opengameart.org/art-search-advanced?field_art_type_tid[]=12 (filter CC0)
- **Kevin MacLeod / incompetech** — https://incompetech.com (CC BY 4.0, attribution required)

Pick tracks with a clear, steady beat (a kick drum on every beat makes echo between
phones very easy to hear, which is what you want for the demo).

The built-in **click track** (120 BPM) is synthesized in the browser and needs no file.
